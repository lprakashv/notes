# Archived original images

This directory preserves replaced or unused legacy raster assets outside the
published MkDocs source tree. Paths below this directory mirror the assets'
former repository locations.

- `Lalit-new-logo-3.png` is the former custom favicon.
- `book/images/diagram-*.png` contains unused system-design notation images.
- `book/images/` contains the raster sources replaced by Kubernetes Excalidraw
  diagrams.
- `book/java/images/` contains replaced Java heap, threading, and class-loader
  diagrams. The archived ZGC images were unreferenced, version-specific legacy
  material and were intentionally not reintroduced into the current note.
- `book/spring/images/` contains replaced Spring architecture, discovery,
  dashboard-annotation, and transaction-proxy diagrams.

Pixel-exact UI and log screenshots that remain relevant stay beside their notes
under `book/`. Archived files are retained for provenance and can be restored if
future notes need their exact pixels.
