# Archived original images

This directory preserves unused legacy raster assets outside the published
MkDocs source tree. Active page images remain beside their notes under `book/`.

- `Lalit-new-logo-3.png` is the former custom favicon.
- `book/images/diagram-*.png` contains unused system-design notation images.

These files are retained for provenance and can be restored or converted to
editable vector sources if future notes need them.
